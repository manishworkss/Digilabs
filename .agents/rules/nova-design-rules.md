# NOVA DESIGN RULES

**Never change:**
- color system
- typography system
- section architecture
- motion philosophy
- spacing philosophy

**Prefer:**
- restraint
- whitespace
- CSS/SVG over heavy media
- transform/opacity animations
- accessible interactions
- performance

**Never:**
- add random sections
- add random gradients
- use excessive glassmorphism
- use excessive animation
- install unnecessary packages
- claim verification without testing

**Approved Architecture:**
Do not change the concept halfway through. Stick strictly to the following flow:

